# TestFlight 25 · обложка июльской новости

База проверки `02f0fb5`. По наблюдению на iPhone правильная обложка — фотография студентов на лестнице. Фиолетовый фон со звёздами — состояние без фотографии. Два описанных кадра относятся к главной. Задержка в «Что нового» сообщена отдельно. Номер установленной на этих кадрах сборки остаётся неизвестным.

Её загрузка в приложении по-прежнему проходит через авторизацию публикации.

## Воспроизведение и исправление

При обновлении приложения файл во временном кэше может отсутствовать, хотя в проверенном снимке Home уже есть фотография. `02f0fb5` включал снимок промобаннеров в подготовку первого кадра, а фото новостей искал отдельно во временном кэше. Тест прошлой версии заранее заполнял этот кэш по текущему ключу, поэтому пропускал воспроизведённый разрыв.

Теперь онлайн-главная может прочитать разрешённую копию из SQLite. Она проверяется по ID и пути объекта через индекс кэша. Более свежая запись с новым путём и фото заменяет раннюю версию вместе со своей обложкой. Удаление временного файла проверяется отдельно от отзыва доступа и ручной очистки. Выбранная картинка декодируется до публикации первого кадра. Читалка использует тот же проверяемый источник без ожидания загрузки из сети при наличии локальной копии.

Тест сравнивает реальные пиксели фотографии и декодированный JPEG на первом кадре. На базовой версии при удержанной сети фото отсутствовало на первом кадре, при возврате и в читалке. После исправления прошли все четыре сценария. Медленная сеть, офлайн, отсутствующий файл при сохранённом индексе и метаданные версии 4 при проверенном снимке версии 5. Нижний промобаннер оставался видимым на главной.
