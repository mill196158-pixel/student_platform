# Повторная проверка студенческого приложения 27 ноября 2026

Рабочий каталог `C:\student_platform`. Проверка по замечаниям в задаче Todoist «iPhone: замечания по чату, новостям, дневнику и задачам» и по E2E-091–100. Для записи и отправки использованы синтетические студенты и изолированные локальные данные.

## Что исправлено

- При холодном запуске iOS заставка показывает установленную иконку. Проверены три масштаба ресурса и одна иконка в storyboard. Flutter-тест подтверждает одного активного персонажа. Индикатор при переходе между вкладками немного увеличен.
- Главная начинает показывать подтверждённые сохранённые данные владельца, пока остальные разделы читают диск или ждут сеть. Профиль офлайн показывает имя, доступные сведения и сохранённый аватар владельца. Смена аккаунта или отзыв доступа убирают данные предыдущего сеанса.
- Новость открывается сразу. Если для неё есть обложка, она появляется по готовности. Если обложка недоступна, остаются заголовок и текст. Свайпы по ленте сохранены. Смена аккаунта и переход офлайн останавливают загрузку обложки текущего сеанса.
- «Данные приложения» показывают объём, лимит и последствия очистки. Подробные замеры открываются через «Дополнительно». Проверены светлая и тёмная темы, ширина 320 px и масштаб текста 160%.
- В чате проверка права на отправку не зависит от права создавать задания. Пока проверка идёт, под полем зарезервировано место. Для архива и недоступной отправки показывается состояние доступа. Шапка «Чат / Файлы» и положение истории сохраняются при фокусе, прокрутке и возврате с вкладки файлов.
- При выборе сообщений виден один индикатор рядом с сообщением. Счётчик, выход, копирование, пересылка и удаление сохранены. Свайп во время выбора не переключает вкладку и не добавляет скрытый черновик ответа.
- Потеря ответа после записи сообщения не запускает вторую запись через «Повторить». При неизвестном результате показывается локальный статус «Доставка не подтверждена». По истории можно сверить доставку, а локальную запись можно убрать отдельно. Две осознанные отправки одинакового текста проходят независимо.

## Сквозные проверки

| Проверка | Результат |
| --- | --- |
| Проектный чат в Windows | Вход → материалы → нужная команда → режим выбора → нативный PDF. Два возврата восстанавливают вкладку и предмет. Проверены пустой и архивный чаты, задержка и отзыв прав, пересылка в точный чат и отправка через локальную базу. |
| Два процесса приложения с локальной базой | Первый процесс сохранил историю. Второй открыл её через материалы без HTTP, сохранил различие между пустой и несохранённой историей и независимость одноимённых предметов разных семестров. После восстановления сети ранее несохранённый чат загрузился. |
| Новости на двух тестовых аккаунтах | Изображения, отсутствие обложки, свайпы по расширенной ленте, сбой сервера и возврат, смена аккаунта и разделение доступа к публикациям. |
