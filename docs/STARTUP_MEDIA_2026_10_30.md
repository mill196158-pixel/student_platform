# Запуск, реклама и аватар — 30.10.2026

Продолжение COLD_START_2026_10_30.md. Цель: убрать ожидание пустой рекламы и повторную загрузку аватара, исследовать остаточные задержки запуска без изменения правил входа.

## Что изменено

- Home и Profile сначала скрывают рекламу. Image-варианты появляются только после получения непустых байтов основного изображения; при ошибке/отсутствующем asset ID остаются скрыты. Текстовые варианты не ждут медиа. Демо не возникает из-за начального пустого состояния загрузки. Серверный порядок и slot сохранены. Admin preview не изменён этой фильтрацией.
- Убрана дополнительная анимация появления промокарточек длительностью 420–630 мс. Картинка и иконка грузятся параллельно. Уже готовые байты остаются в существующем grant/account/version-scoped кэше; его разрешения и сроки не продлены.
- Impression записывается после кадра только для готовой карточки, пересекающей viewport активной главной, без перекрывающего маршрута. Загрузка данных, неактивная вкладка и карточка за пределами viewport не считаются показом.
- Аватар текущего проверенного пользователя прогревается асинхронно с главной и передаётся в профиль через ImageProvider. Публичные avatars своего Supabase origin используют дисковый кэш с ключом UID + полный URL/version и ограничением декодирования 264×264. Подписанные/чужие URL не получают нового дискового кэширования. Смена URL меняет ключ; отсутствие аватара очищает изображение. Это не обещание мгновенной первой загрузки без сети.
- `ContentMediaService` ограничивает каждый network invoke/GET 12 секундами. Зависший запрос освобождает single-flight для повторной попытки. Timeout расположен на сетевом await: поздний ответ не продолжает сохранение байтов. Закрытые файлы не становятся публичными.
- Firebase bootstrap теперь ожидает `waitUntilFirstFrameRasterized` внутри single-flight, в том числе при вызове из PushSessionHost. Framework post-frame callback был раньше rasterization. Не добавлен фиксированный таймер; background handler, getInitialMessage, session guards и авторизация маршрутов сохранены. Rasterization не равна точному моменту показа дисплеем.
