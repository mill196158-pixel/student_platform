# Открыть Student Platform на Mac и проверить iPhone

Это исходники в отдельной ветке `codex/student-todoist-20261125`. GitHub не публикует приложение в App Store и не изменяет базу данных. Сборка по умолчанию может подключаться к рабочему серверу: используйте тестовый аккаунт и не отправляйте сообщения или файлы в реальные чаты без необходимости.

## Подготовка

Нужны macOS, Xcode с установленными компонентами iOS, CocoaPods, Git и Flutter. Для закреплённого Firebase Apple SDK 12.15.0 официально поддерживается Xcode 26.2 и новее. Проверки этой ветки на Windows выполнялись на Flutter 3.47.2 / Dart 3.13.2. Минимальные версии зависимостей по `pubspec.lock`: Flutter 3.41 и Dart 3.11. Совместимость с установленным на Mac Xcode нужно подтвердить там командой `flutter doctor -v`. [Требования Firebase 12.15.0](https://firebase.google.com/support/release-notes/ios#version_12150_-_june_16_2026).

Если проект уже есть на Mac, перейдите в его каталог и обновите ветку этими командами.

```bash
git fetch origin
git switch codex/student-todoist-20261125
git pull --ff-only
```

Затем выполните команды подготовки начиная с `flutter doctor -v` из блока ниже. Для первой установки используйте блок целиком.

```bash
git clone --branch codex/student-todoist-20261125 https://github.com/mill196158-pixel/student_platform.git
cd student_platform
flutter doctor -v
flutter pub get
flutter precache --ios
cd ios && pod install && cd ..
open ios/Runner.xcworkspace
```

Открывайте именно `Runner.xcworkspace`. В Xcode выберите target Runner, затем Signing & Capabilities и свою команду Apple Developer. Текущий Bundle ID: `com.mill453020.studentplatform`; для уже существующего приложения он должен совпадать с App Store Connect. Минимальная версия iOS в проекте — 15.0. Доступы Apple, сертификаты, provisioning и APNs с этого компьютера не проверялись и в Git не помещаются.

## Проверка на телефоне

Подключите iPhone, разрешите доверие компьютеру и при необходимости включите Developer Mode. Установите сборку **Release**, чтобы приложение открывалось с иконки после отключения Mac. Отладочная сборка Flutter на iPhone требует запуска через Xcode или Flutter и подключения отладчика.

После настройки подписи в Xcode посмотрите идентификатор телефона и установите сборку:

```bash
flutter devices
flutter run --release -d <идентификатор_iphone>
```

Для установки из Xcode выберите подключённый iPhone. В меню **Product → Scheme → Edit Scheme → Run → Info** выберите **Release** в поле **Build Configuration**, снимите флажок **Debug executable** и нажмите **Run**.

После установки закройте приложение, отсоедините iPhone от Mac и откройте приложение с иконки. Войдите под тестовой учётной записью и откройте тестовый чат. Проверьте первое сообщение, меню долгим нажатием, возврат из вложения. Откройте историю чата с сетью, затем проверьте запуск в авиарежиме и возврат связи. Для проверки APNs снова откройте приложение, сверните его или заблокируйте телефон, отправьте тестовое сообщение со второй учётной записи и откройте нужный чат из уведомления. Итоговое значение `aps-environment` зависит от подписанного профиля.

[Режимы сборки Flutter](https://docs.flutter.dev/testing/build-modes) · [Подготовка iPhone для Flutter](https://docs.flutter.dev/platform-integration/ios/setup)

## TestFlight и App Store — после проверки

Номер сборки в `pubspec.yaml` сейчас `1.0.0+18`; перед новой загрузкой в App Store Connect используйте номер build, который ещё не загружен для этой версии. Выберите **Release** также для действия **Archive** в Xcode или выполните `flutter build ipa --release` после настройки подписи. Затем загрузите сборку в App Store Connect, проверьте её через TestFlight и только после этого отправляйте на проверку Apple. Инструкция: https://docs.flutter.dev/deployment/ios

## Известные ограничения текущей проверки

- Сборка и запуск iOS/macOS на реальном Mac не выполнялись; работу APNs, подписи и все ссылки пользовательского контента надо проверить на устройстве.
- На Windows прошли 172 проверки пакета `student_ui`, включая эталонные снимки. Проверены размеры и прозрачность ресурсов иконки для всех 19 записей каталога iOS.
- SQL-миграции включены в исходники; Git не запускает их на сервере. Защита гостевого каталога от показа скрытых или архивных предметов применена к основной базе 5 ноября 2026 года: `20261105000711_guest_group_visibility_guard.sql`. Истории локальных и серверных миграций содержат расхождения: не запускайте массовое применение миграций без отдельной сверки, проверки состояния и резервной копии.
