# Гостевой режим: новости, группа и профиль — 30.10.2026

## Реализовано
- Настоящая серверная новость вместо встроенной заглушки. До шести независимых загрузчиков обложек, один повтор при временном сбое, защита от устаревшего ответа при обновлении. Отдельный ограниченный дисковый кэш по пути и версии.
- Выбор одной из опубликованных групп, сохранение в guest_selected_group_v1. После закрытия процесса группа восстанавливается. Серверный guest-account/идентификатор устройства не создаётся; персональные кэши аккаунта не читаются и не изменяются.
- Гостевое расписание по выбранной группе: день/неделя, календарь, предыдущая/следующая неделя. Сервер ограничивает запрос семью днями и 200 строками; teacher/user/author поля не выдаёт.
- В гостевом профиле удалены дневник, избранное и блок «На этом устройстве». Старые локальные записи физически не удалены. Карта СПбГАСУ открывается без входа.
- «Обучение»: короткое объяснение команд/чатов/заданий и общий экран преимуществ аккаунта.
- Дизайн общих шапок и навигации сохранён; showDiary по умолчанию true, авторизованный профиль не меняется.

## Сервер
Применены 20261030151803_guest_public_read_surface и 20261030152702_guest_news_signed_media. Развёрнута guest-news-media.
Новости публикуются для гостя только с guest_visible=true, дополнительно status=published, не скрыты, в активном окне, audience=all и без любых адресных связей. Включена только проверенная существующая новость «Новое приложение». Новые новости по умолчанию закрыты для гостя.
Группы разрешены отдельным private.guest_public_groups; пользователь не может редактировать этот список. Новых широких grants на таблицы нет.
Прямой анонимный Storage-доступ не используется: bucket остаётся private, публичная Edge-функция принимает только ID разрешённой новости и выдаёт ссылку на 300 секунд. Подписанные URL не сохраняются. После скрытия новости новая выдача прекращается; ранее выданная ссылка действует не более пяти минут. Дисковый файл не показывается без актуальной серверной записи. Уже открытый экран обновляет выдачу при refresh/следующем запуске.

## Ограничения и найденные прежние риски
- В базе сейчас нет занятий после 23.06.2026; механизм чтения работает, осенние данные не выдумывались и не импортировались.

- Обнаружен прежний риск: public.groups имеет authenticated write grants и выключенный RLS. Состав private allowlist защищён, но значения groups всё ещё подвержены прежнему authenticated write риску; прежние права самой таблицы этим изменением не исправлены.
