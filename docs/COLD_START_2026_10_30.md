# Холодный запуск: 30.10.2026

## Изменения

1. Splash больше не выполняет повторную live-проверку `must_change_password`: единственная проверка остаётся в async redirect GoRouter, до создания защищённого экрана. Ошибка проверки ведёт на вход. Восстановление/refresh сессии и очистка старых prefs сохранены.
2. Убрана загрузка профиля через `AppSession.loadFromServer` перед открытием главной. Поиск по lib/test/integration_test не обнаружил читателей этого legacy-состояния; главная получает профиль своим репозиторием.
3. На native Android не ожидается повторный `SystemChrome.setPreferredOrientations`: MainActivity уже имеет `screenOrientation="portrait"` в исходном и merged manifest. На других платформах прежнее ожидание сохранено.
4. Добавлены измерения этапов native Activity/plugins/Flutter UI по явному intent-флагу `startupTrace`; Dart-маркеры доступны в profile/debug, в release только с `STARTUP_TRACE=true`. Логи содержат времена, без токенов, payload и идентификаторов пользователя.

Firebase, refresh-token flow, серверные права, RLS и обработчики доставки пушей этим изменением не модифицируются. Предыдущая single-flight инициализация Firebase после первого кадра сохранена.

## Release: установка и контроль

Release APK x86_64 успешно собрана и установлена с сохранением данных: **64,0 МБ** (profile 157,0 МБ). Используется существующая debug signing configuration, поэтому это сборка для эмулятора, не подписанный магазинный релиз. Включён только диагностический `STARTUP_TRACE=true`. Первый build столкнулся с изменением GeneratedPluginRegistrant параллельным Flutter test (`integration_test` отсутствует в release); последовательная пересборка после завершения тестов успешна. Это конфликт генерируемого файла, без правки зависимостей приложения.

Первая серия после установки: 12182 / 8095 / 4658 мс, медиана 8095. Её первый запуск начат до получения финального результата install-команды, поэтому это диагностическая, а не контролируемая серия. Повторная контрольная серия после подтверждённой установки и завершения всех сборок/тестов, стандартный Impeller: **4744 / 2638 / 3394 мс**, медиана **3394 мс** до отображения Flutter UI. До первого Home snapshot после этого ещё примерно **655 / 867 / 710 мс**. Это частичные данные, не завершение всех сетевых загрузок.

Диагностическая серия с intent `enable-impeller=false`: 3083 / 2323 / 3370 мс, медиана 3083. Диапазоны перекрываются; позднейший стандартный режим также быстрый. Убедительной причины отключать Impeller для всех пользователей нет; opt-out к тому же помечен установленным Flutter как deprecated. **APK и окончательный запуск используют стандартный движок.** Скрипт допускает этот флаг только как явно запрошенную диагностику.

Итого: лишняя работа startup удалена, тесты проходят, установленная release-сборка открывается в контрольной серии за 2,6–4,7 с. Устойчивое ускорение именно от изменения кода и отсутствие редких долгих запусков пока не доказаны; обещания «всегда быстрее секунды» нет. Основная остаточная вариативность видна до Dart main и между framework first-frame callback и native UI-displayed. Точный источник этой вариативности не установлен.

Analyzer затронутых Dart-файлов: 0 errors, 0 warnings, одно прежнее info о deprecated anonKey в main.dart. Итоговые файлы: cold-release-control.json, cold-renderer-check.json, cold-release-build-final.txt. GitHub push не выполняется.
