# Одна сборка: публичная польза и личная учёба

Предложение основано на семи предоставленных скриншотах конкурента.
Его сервер, скорость, полнота данных и реальный набор функций не проверялись.
Видны расписание, поиск пары/аудитории, группа, преподаватели с рейтингом,
профиль с ДЗ, справочник студента, темы и уведомления. Это хороший ориентир
по повседневным задачам, но не доказательство качества исполнения.

## Рекомендуемая навигация: четыре постоянных раздела

| Раздел | Без аккаунта | После входа / закрытая бета |
|---|---|---|
| **Учёба** | Предмет → тема → разобранный пример → шаблон/материал; поиск и фильтры | Мои предметы, задания и прогресс |
| **Расписание** | Выбор группы локально, опубликованные занятия, даты обновления | Моя группа, личные заметки, напоминания |
| **Сервисы** | Калькуляторы, инструкции, шаблоны, справочник по справкам/сессии/общежитию | Персональные обращения, если появится обоснованная необходимость |
| **Моё** | Локальное избранное, недавние материалы, тема, настройки, вход | Дневник, профиль, группа, друзья и сообщения |

Верхняя строка: контекст группы (если выбран) и поиск внутри текущего раздела.
Первое открытие сразу показывает материалы, без обязательного выбора вуза и группы.
Группу запрашивать при открытии расписания. Закладки доступны без входа.
Внутри «Моё» сообщения имеют отдельный счётчик; в бете измерить, насколько
часто ими пользуются. Пятую вкладку «Общение» добавлять при подтверждённой
потребности, не дублируя друзей/группу в нескольких независимых разделах.

Не смешивать «публичный справочник» с текущими личными RPC раздела Info:
для гостей нужна отдельная серверная выдача только разрешённого контента.
Гостевой просмотр расписания с ФИО преподавателя также требует отдельной
оценки состава/оснований публикации; публичность источника не считать разрешением.

## Две альтернативы

1. **Пять вкладок:** Главная / Учёба / Расписание / Общение / Моё.
   Подходит после появления активной социальной части. Сервисы находятся
   внутри Учёбы; Главная содержит продолжение работы и ближайшие события,
   а не ещё одну копию каталога.
2. **Три вкладки:** Материалы / Инструменты / Моё.
   Самый узкий первый выпуск. Расписание и общение остаются доступными
   тестовой группе внутри Моё. Меньше публичных сценариев для приёмки,
   но слабее причина открывать приложение каждый день.

Для текущей цели рекомендован первый вариант с четырьмя вкладками.
Это предложение, не выполненная перестройка интерфейса и не удаление функций.

## Чем пытаться стать полезнее показанного бота

- Единая карточка предмета: примеры, материалы и инструменты; после входа —
  задания и занятия этого же предмета. Не заставлять искать один предмет
  отдельно в расписании, материалах и чате.
- Поиск по конкретной задаче: «эпюра», «интерполяция», «справка», с понятными
  типами результатов, актуальностью и источником материала.
- Сохранённые материалы доступны без сети; у расписания видна дата последней
  синхронизации. Старые данные не выдаются за актуальные.
- Для каждого примера: условие, шаги решения, обозначения/единицы, файл,
  частые ошибки. Контент публиковать при наличии прав, без чужих персональных данных.
- Путь «не понял задачу → нашёл пример → применил инструмент → сохранил»
  должен работать без регистрации. Аккаунт нужен, когда пользователь выбирает
  синхронизацию или взаимодействие с другими людьми.
- Не показывать технические идентификаторы в обычном профиле. Рейтинг
  преподавателей не делать главной ценностью: ему нужны модерация, правила
  и достаточное количество отзывов.

## Порядок выпуска

1. Закрыть воспроизводимость локального backend и критические сценарии.
2. Добавить гостевой shell и минимальный полезный набор авторских материалов.
3. Проверить гостя без активной сессии, при отказе сети и после перезапуска;
   личные данные не должны оказаться в гостевом кэше.
4. В одной сборке включать личные функции по серверному списку допуска.
   Тестировать на вымышленных аккаунтах; реальных тестировщиков подключать
   после подготовки правил обработки данных и инфраструктуры.
5. Подписанная APK для пилота, затем выбранный магазин. Скрытая вкладка,
   APK и закрытая группа не заменяют требования к обработке персональных данных.
