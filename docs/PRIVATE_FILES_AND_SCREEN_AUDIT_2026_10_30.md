# Приватные вложения и проверка экранов — 30.10.2026

## Выполненные изменения

Основная база использована с разрешения владельца. Записи для проверки создавались в отдельной синтетической группе и трёх синтетических аккаунтах; существующие учебные материалы не изменялись.

- В Object Storage закрыты прямые публичные GET для `chats/*` и `diaries/*`. Проверка после применения: unsigned/forged 403, signed GET/HEAD 200, Range 206, PUT 200. Контрольный публичный объект вне этих каталогов остаётся доступен. Политика сначала проверялась на отдельных объектах; восстановление предыдущей политики проверено до полного включения.
- Сервер выдаёт ссылки на 60 секунд только после проверки прав. Истёкшая ссылка действительно возвращает 403. Постоянные подписанные ссылки не записываются в сообщения.
- Обычные вложения доступны читателям чата, включая разрешённую сохранённую архивную историю. Подтверждения оплаты — только отправителю и организатору; офлайн-кэш для них отключён. Личный дневник — только автору записи, независимо от текущей группы.
- Реестр объектов проверяет происхождение, владельца, размер и тип через подписанный HEAD после PUT. Клиент не может подменить ключ/URL/размер при регистрации. Существующие 50 файлов чатов и 7 файлов дневника перенесены в реестр.
- Создание сбора, карточки и привязка вложений выполняются атомарно. Повтор одного запроса возвращает тот же сбор; изменённое содержимое с тем же ключом отклоняется. Поддержано до 10 вложений сбора.
- Пересылка в другой чат создаёт отдельную разрешённую копию и заменяет ссылки во вложенной структуре сообщения. Получателю не требуется членство в исходном чате.
- Кэш разделён по аккаунтам. Серверный отказ удаляет локальную копию; временный сетевой сбой допускает ранее загруженную копию до 24 часов. Logout очищает приватный кэш. Уже скачанный пользователем файл невозможно отозвать удалённо.
- Дневник больше не загружает и не удаляет объекты прямым S3-клиентом: используется подтверждаемая загрузка, серверная привязка и очередь очистки. Ошибки загрузки, привязки и удаления вложений больше не скрываются. Повтор не дублирует вложения.
- Исправлен запрос одногруппников к отсутствующему столбцу `users.city`.

Старым APK с прямыми публичными URL необходимо обновление: серверная защита намеренно не оставляет им публичный обход.

Последняя строка — проверка отображения, не всех действий этих экранов. Предмет использовался черновой, поэтому проверено также состояние `not_found`; преподаватель — fallback по синтетическому имени. Камера, системный выбор файлов и push на физическом телефоне этим прогоном не подтверждены.

Итог: 322 unit/widget-теста PASS; Deno check трёх Edge Functions PASS; анализ всех изменённых Dart-файлов приложения — без замечаний (16 предупреждений/info устранены). Дополнительный Android-прогон после полного закрытия хранилища: кэш/временные файлы/logout, дневник с 16 экранами, межчатовая пересылка — 3/3 PASS. Отдельный повтор друзей/профиля PASS.

Настоящий обработчик очистки удалил один тестовый orphan без ошибок; перед запуском проверено отсутствие других ожидающих объектов. Затем 27 объектов фикстуры и четыре контрольных объекта удалены с подписанной проверкой 404. Три Auth-пользователя, группа, команды и четыре чата отсутствуют в БД; 27 временных строк реестра удалены. Диагностический `storage-access-audit` заменён на standalone HTTP 410 без кода подписи. Рабочая политика совпадает с `supabase/storage/private-attachments-policy.json`.

Независимый review: APPROVE для этого среза. Во время teardown тестов пересылки встречался закрытый HTTP-клиент у фонового mark-read; отправка, получение и права файлов подтверждены отдельными assert. Это не проверка push/фоновой работы на физическом устройстве.

## План разделов одной сборки

| Раздел | Без входа, план | После входа |
|---|---|---|
| Учёба | Поиск, предметы, опубликованные объяснения/примеры, локальное избранное | Мои предметы, задания, личный дневник |
| Расписание | Выбор группы и просмотр разрешённого расписания | Личные заметки и напоминания |
| Сервисы | Калькуляторы, шаблоны, инструкции по учебным вопросам | Синхронизация личных сохранений при необходимости |
| Моё | Настройки, избранное, вход | Профиль, группа, друзья, чаты, сборы; доступ закрытой беты проверяется сервером |

Это план навигации, а не уже выполненная переделка. Не создавать отдельные версии предмета/задания в каждой вкладке: одна сущность и переходы к ней. Гостевой режим сам по себе не доказывает отсутствие обработки персональных данных.
