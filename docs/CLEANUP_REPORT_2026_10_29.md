# Очистка исходников и варианты выпуска — 29.10.2026

## Выполнено

- Инвентаризированы 247 Dart-файлов lib; найдены 47 файлов с классами Screen/Tab.
  Дополнительно составлена карта страниц Admin. Граф учитывает conditional imports.
- Удалены 8 недостижимых старых файлов: альтернативные app/theme/demo user,
  копия team details, старый assignment-details export, старый assignments tab
  и его card, тестовый экран загрузки файлов. Активные варианты сохранены.
- Удалены неиспользуемые _PeekCard/_PeekActionsBar в списке чатов, лишние импорты,
  второй неиспользуемый сценарий входа и _currentLogin старого fallback.
- Profile больше не делает loadTeams + N getMainChatId ради никем не используемого
  списка. Счётчик unread_total сохранён. Ошибка preferences не прерывает выход.
- Неоткрытые вкладки не монтируются сразу. После первого посещения состояние
  сохраняется; тест проверяет отложенное создание и сохранение текста.
- Ранее сделанные в этой сессии auth/logout fixes, закрытие опасных RPC,
  anonymous grants, guard пустого push-cron и PDF compatibility patch включены
  в один локальный проверенный пакет. Это не новая публикация на сервер.

- Student Web release: PASS. Сборка выполнялась после основного cleanup;

- dart analyze lib: ошибок нет, 195 замечаний (43 warning, остальное info),
  против 210 в первом прогоне. Анализатор не объявлен зелёным.
- Shared UI golden residual: 16 старых несовпадений изображений остаются открыты;

Скорость запуска не измерена на физическом телефоне: гарантируем удаление
конкретных лишних запросов и отложенное создание вкладок, не произвольный
процент ускорения. Все пользовательские сценарии вручную не пройдены.
Проверка всего кода не равна переписыванию каждого экрана.
