## Работает в гостевом режиме

- Главная: переходы в материалы, команды и локальный план.
- База: три встроенных учебных материала, поиск, чтение и избранное. Источник обозначен прямо: «Встроенный материал · доступен без сети».
- Обучение: по прямому уточнению пользователя только приглашение войти в команды и чаты предметов. После входа остаётся текущий список команд.
- Расписание: существующий MiniCalendar, локальный план на выбранный день, создание, редактирование и удаление записей. Это НЕ автоматическое расписание группы: ограничение написано на экране.
- Профиль гостя: вход, локальные заметки и избранное. Данные хранятся отдельно в guest_workspace_v1, не объединяются с аккаунтом и не удаляются обычным logout.

Не создаются authenticated tab objects, presence/chat warm и персональные подписки гостевых вкладок. Firebase bootstrap из main пропускается без сессии; после входа его запускает прежний PushSessionHost. На Android отключены native automatic FCM token initialization и analytics collection; явная регистрация токена после авторизации сохранена. Это не доказательство отсутствия всех сетевых обращений ОС/SDK и не юридическое освобождение от 152-ФЗ.
