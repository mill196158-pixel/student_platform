# Гостевой режим: первая рабочая версия — 30.10.2026

Одна APK, текущая NavigationScreen и пять вкладок. /guest — отдельная публичная ветка. /home, личный дневник, профиль и другие персональные маршруты сохраняют проверку сессии и live password policy. Без сессии Splash ведёт в гостевой режим; форма входа содержит «Продолжить без входа», выход из аккаунта ведёт в /guest.

## Работает в гостевом режиме

- Главная: переходы в материалы, команды и локальный план.
- База: три встроенных учебных материала, поиск, чтение и избранное. Источник обозначен прямо: «Встроенный материал · доступен без сети».
- Обучение: по прямому уточнению пользователя только приглашение войти в команды и чаты предметов. После входа остаётся текущий список команд.
- Расписание: существующий MiniCalendar, локальный план на выбранный день, создание, редактирование и удаление записей. Это НЕ автоматическое расписание группы: ограничение написано на экране.
- Профиль гостя: вход, локальные заметки и избранное. Данные хранятся отдельно в guest_workspace_v1, не объединяются с аккаунтом и не удаляются обычным logout.

Не создаются authenticated tab objects, presence/chat warm и персональные подписки гостевых вкладок. Firebase bootstrap из main пропускается без сессии; после входа его запускает прежний PushSessionHost. На Android отключены native automatic FCM token initialization и analytics collection; явная регистрация токена после авторизации сохранена. Это не доказательство отсутствия всех сетевых обращений ОС/SDK и не юридическое освобождение от 152-ФЗ.

## Проверки

- Full root suite: 366 PASS до последних UX/storage правок.
- Auth/session/cold push + guest: 12 PASS после основной правки.
- Финальная guest suite: 3 PASS, включая пять вкладок без Supabase initialization и с запрещённым HttpClient (0 запросов), приватный route guard, чтение сохранённых заметок, раздельный account cache, повреждённые rows, pending write блокировку и rollback при ошибке.
- Независимый review: APPROVE после исправления локальной валидации, rollback и busy input.
- Прежняя инициализация account caches в main сохранена: исключена регрессия восстановления черновиков при первом входе из гостя. Это существующий legacy-механизм, не заявляется новый account-scoped GlobalCache.

## Открытые задачи до публичного выпуска

Публичная серверная выдача новостей/материалов/расписания не внедрена. Текущие персональные RPC и private Storage не раскрывались. Нужен отдельный явный признак публикации для гостей и проверяемый публичный API. Три стартовых материала не являются каталогом всего существующего контента. Не подтверждены настоящая доставка FCM на телефоне, iOS guest privacy и юридическая готовность выпуска. Концепт из картинок выполнен частично: общий shell и режимы работают, публичные server-fed блоки ещё отсутствуют.
