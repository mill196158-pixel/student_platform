## 🔧 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

### Проблема: "function is not unique"
**Решение**: Выполните сначала:
```sql
DROP FUNCTION IF EXISTS public.get_chat_messages_for_team(uuid);
DROP FUNCTION IF EXISTS public.get_chat_messages_for_team(uuid, int);
```

### Проблема: Файлы не отображаются
**Решение**: Проверьте что в `chat_files` есть записи с `message_id`:
```sql
SELECT * FROM chat_files WHERE message_id IS NOT NULL LIMIT 5;
```

### Проблема: Ошибка в Flutter
**Решение**: Проверьте что `Message.fromJson` правильно парсит `attachments`
